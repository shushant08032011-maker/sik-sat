The Mission

SIK-SAT is designed as a student engineering project for exploring satellite-style systems and wireless communication technology.

🛰 Satellite System

A compact experimental platform integrating embedded electronics, sensors and communication technology.

📡 LoRa Communication

Wireless telemetry communication between the SIK-SAT platform and the Ground Station.

📊 Telemetry

Live monitoring of sensor data, battery information, signal strength and system status.

🧪 System Testing

The Ground Station software can be developed to perform system checks and monitor incoming data.
